# StreetBeat

**Music that runs at your pace.** A music player for runners: it listens to your steps and speeds up or slows
down each song, keeping its pitch, so the beat matches your stride. Coming soon to iPhone and Android.

This repository holds only the app's website: https://pippodima.github.io/streetbeat/

- [Privacy policy](https://pippodima.github.io/streetbeat/privacy.html)
- [Support](https://pippodima.github.io/streetbeat/support.html)

Music from [Audius](https://audius.co), by independent artists. "StreetBeat" is a working name.
